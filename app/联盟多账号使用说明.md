# 联盟多账号窗口

双击同目录“启动联盟多账号.bat”或“联盟多账号.pyw”；也可运行 python union_batch_gui.py。

刷新已保存账号，选择界面槽位后添加。每账号只能添加一档，不自动选中或执行。槽位默认0；可点“探测存档”读取各槽战力并自动选中最高战力槽，或点“探测名单存档槽”批量修正已添加账号的槽位（只查询，不执行任务）。可在“联盟事务”子页面执行联盟贡献、联盟Boss或联盟药园，在“星斗 / 补贡”子页面执行星斗幻境和一键购买补贡券，在“蛮荒组队”子页面选中2~3个账号开打多人蛮荒，在“狗卡”子页面执行免费狗卡。星斗幻境只领免费周箱并续接通关；补贡券只用星辰石在星斗商店兑换（周限3张），两者都不消耗点券。Boss默认使用新版面板技能估算模型。

药园二级密码仅本窗口及子进程环境传递，不写临时批次文件。关闭窗口会停止子进程；未知写结果不要盲目重跑。
